# Telco Churn — An Economic Approach to the Retention Threshold

End-to-end churn pipeline on the IBM Telco dataset. The novelty is not the model but the way the decision threshold is picked: by maximising net monetary value instead of a statistical metric.

The analysis, assumptions, results and methodology are in the PDF reports:

- [report.pdf](reports/report.pdf) — English version
- [rapport.pdf](reports/rapport.pdf) — French version

## Install

Python 3.11. From the repo root:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Dataset

The Telco dataset is not committed. Download it from Kaggle (search "Telco Customer Churn") and place the CSV at `data/WA_Fn-UseC_-Telco-Customer-Churn.csv`.

## Running the pipeline

Train the model, calibrate probabilities, run the sensitivity analysis, and write the serialised artefacts to `models/`:

```bash
python -m src.train
```

Score a batch of new subscribers under a chosen scenario (defaults to central):

```bash
python -m src.predict --input data/new_subscribers.csv --output predictions.csv --band central
```

Regenerate the figures used in both reports:

```bash
python reports/code/make_figures.py
```

## Methodological choices

- **XGBoost** for the final model. Logistic regression and Random Forest were tried first and are kept in the exploration notebook as baselines.
- **Three-level split** (fit / cal / test), stratified on the target. Calibration runs on data the estimator has never seen.
- **Platt scaling** on top of a `FrozenEstimator`. The point is not to improve ranking, which XGBoost does well, but to produce probabilities that can be plugged into a monetary formula without lying.
- **Threshold by maximum net value, not by precision/recall trade-off.** The expected value of acting on each subscriber is computed subscriber by subscriber (uses the individual `MonthlyCharges`), not from a group average.
- **Horizon via Kaplan-Meier RMST** on `tenure`, with churn as the event and active subscribers as right-censored. The naive alternatives (mean tenure of leavers, inverse of monthly churn rate) are discussed and discarded in the report.
- **Three scenarios** (conservative, central, optimistic) over the three assumed inputs. The recommendation holds across all three.
- **Strict schema validation at inference.** A missing column raises an explicit error before any call to the model. Silent misalignment is the one failure mode this pipeline refuses to allow.
- **Traceability.** The threshold artefact carries the four assumptions that produced each scenario's threshold. A flagged subscriber can be traced back to the exact economic hypothesis under which they were flagged.

## Scope

Residential subscribers only. The B2B portfolio has different churn dynamics and is out of scope.
